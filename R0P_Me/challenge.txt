================================================================================
R0P_ME
======

Level    : Medium
Category : Pwn / Binary Exploitation
Binary   : r0p_me

## THE CHALLENGE

    Controlling the return address is only the beginning.

    You have been given only the binary. Somewhere inside it is a function
    that can be reached through a carefully crafted payload, but reaching it
    alone will not be enough.

    This time, the program expects something more than just a jump.

## YOUR MISSION

    Investigate the binary and understand how it handles input.

    Find the vulnerability.
    Determine the offset needed to overwrite the saved return address.
    Locate the function you want to reach.
    Figure out how to satisfy its requirements using the calling convention.

    You may find the following tools useful:

        gdb
        objdump
        readelf
        file

## FIRST STEP

    Start by examining the binary:

        file r0p_me

    Then inspect its functions, run the program, and investigate what happens
    when you provide more input than expected.

    Once you understand how to control execution, try your exploit against
    the server:

        (your_payload; cat) | nc localhost 1340

The "cat" keeps stdin open after the payload is sent, allowing you to
interact with the shell spawned by the program.

If your exploit works, you should gain access to a shell.
