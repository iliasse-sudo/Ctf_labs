## THE CHALLENGE

Something is wrong with this program.

You have been given:

```
- the source code: main.c
- the binary: oopsie
```

Your goal is to investigate the program, understand how it behaves, and
figure out what happens when it receives unexpected input.

Start by reading main.c carefully.

---

## YOUR MISSION

Investigate the binary.

Run it.

Experiment with different inputs.

Observe what changes.

Then use the tools available to you to understand why.

Useful tools may include:

```
./oopsie
gdb
file
objdump
readelf
```

You are not expected to know everything before starting.

The source code is there for a reason.

---

## FIRST STEP

Start with:

```
cat main.c
```
---

Then try running the program normally.

There is no need to guess the answer.

Investigate it.
